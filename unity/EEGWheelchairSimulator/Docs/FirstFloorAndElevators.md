# 1층 및 엘리베이터

## 실행

- 기존 `Assets/Scenes/ConvergenceHallB1Scene.unity`에 1층과 엘리베이터를 함께 연결했다.
- 기본 실행과 RESET은 지하 1층에서 시작한다. `ConvergenceHall1FScene.unity`에도 같은 B1 시작 위치를 저장하며 PgUp으로 1층을 확인할 수 있다.
- Unity Play → START → 엘리베이터 문 앞에서 **문 열기 / 호출** → 완전히 탑승 → **B1 / 1F** 선택 → 도착 후 **START**로 하차한다.
- 기존 E 문 조작, V 1·3인칭 전환, F 자유 시점을 유지한다. PgUp/PgDn은 별도의 층 바로가기다.

## 엘리베이터 동작

- 동쪽(B112 옆) 및 서쪽(B109 옆) 승강기를 각각 1층 승강기와 연결했다.
- 문 닫힘 → 약 2.5초 이동 표시 → 도착 층 문 열림 순서다.
- 휠체어 전체가 1.7 × 1.5m 객실 내부에 있어야 출발한다. 출입구에 걸쳐 있으면 출발을 거부하며, 문 닫힘은 기존 충돌 검사로 멈춘다.
- 이동 중 START, 키보드/Python 주행, 자유 시점, 층 바로가기를 잠근다. 도착 후에는 정지 상태를 유지하고 START로 다시 주행한다.
- RESET은 이동을 취소하고 원래 시작 위치와 문 상태를 복원한다.
- 화면이 가려진 동안 도착 객실 중앙으로 이동하고, 출입문을 바라보도록 방향을 맞춘 뒤 문을 연다. START 후 W 전진으로 하차할 수 있다. 승강로 내부의 물리적 카 이동은 구현하지 않았다.

## 1층 범위

제공된 피난안내도와 사진을 기준으로 101–123호 및 107-1호 공간 외곽, 출입문, 복도, 흰색/남색 천장, 반투명 유리 구간, 블루벨리 목재 계단과 난간, 긴 카운터와 의자 11개, 두 엘리베이터실을 구현했다. 기존 B1 계단의 높이에 1층을 맞췄다.

도면은 실측 도면이 아니므로 방과 복도 치수는 추정치다. 1층 강의실에는 책상·의자·칠판을 배치하고 호실 표지판은 B1 형식에 맞췄다. 블루벨리에는 두 면의 난간 카운터와 실내 좌석을 배치했다. 동·서 계단실 모두 지하 1층과 1층을 연결한다. 자유 시점에서 계단에 접근하면 계단 경로를 따라 오르내릴 수 있다. 휠체어로 층을 이동할 때는 엘리베이터를 이용한다.

엘리베이터 옆 나무 책상은 제거했다. 1층 화장실 네 곳은 B1과 같은 반투명 유리문, 금속 프레임과 긴 손잡이, 벽·걸레받이 마감 및 회색 타일 바닥을 사용한다.

## 검증

- 복도 중심 경로 255개 지점에서 실제 휠체어 크기의 충돌 검사
- 1층 모든 문 30/120fps 개폐 및 다른 층에서 문 조작 방지
- 두 승강기 각각 B1↔1F 왕복, 탑승·하차 경로, 문 끼임, 이동 중 입력 차단
- 문 닫힘/이동/문 열림 중 RESET
- 양방향 도착 시 문을 바라보는지, W 전진만으로 하차할 수 있는지 검사
- 두 계단실의 양쪽 벽과 뒷벽 높이별 충돌·렌더링 및 천장 확인
- 블루벨리 옆 1층 엘리베이터실의 B1 콘크리트 마감·점검문·객실 구성 확인
- 실제 프레임 업데이트와 화면 버튼으로 왕복 실행 및 이미지 캡처

재생성: `Tools > EEG Wheelchair > Build Photo Based First Floor`.
주요 스크립트: `ConvergenceHallFirstFloor`, `ConvergenceHallElevatorTravel`, `PassengerElevator`.
기존 B1 환경 프리팹은 수정하지 않고 씬에서 1층 연결 부분만 재정의한다.
